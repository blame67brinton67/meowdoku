# MeowDoku 本機遊戲站

## 啟動

```bash
npm install
npm start
```

開啟 `http://localhost:3000`。要讓朋友加入，可啟動 ngrok：

```bash
ngrok http 3000
```

## 帳號與資料庫

玩家可在右上角「登入 / 註冊」建立帳號（帳號 3–20 個英數字、`_`、`-`；密碼
8–72 字，常見弱密碼會被擋下）。不登入也能以訪客身分玩單人與多人，但訪客的
進度與紀錄在關閉瀏覽器後不保證留存；在同一個瀏覽器分頁裡註冊或登入時，
該次訪客的進度會自動併入帳號。

帳號、session、帳號進度與對戰紀錄存在 SQLite 檔 `data/meowdoku.db`（含
`-wal`/`-shm` 附屬檔）。**`data/` 現在不是可丟棄目錄**：請保留並定期備份
`data/meowdoku.db`；`.gitignore` 已排除該檔，請勿把它 commit 進 repo。
訪客進度仍寫在 `data/scores.json` 與 `data/match-history.json`。

## 管理員

管理員身分存在 `users.is_admin`，沒有共用密鑰。建立第一個管理員：

1. 先在網頁上註冊要當管理員的帳號。
2. 以環境變數 `ADMIN_BOOTSTRAP_USER=<帳號>` 重啟伺服器，啟動時會把該帳號
   標記為管理員（帳號不存在只會印一行提示）。之後不必再帶這個變數。

```bash
ADMIN_BOOTSTRAP_USER=alice npm start        # bash
$env:ADMIN_BOOTSTRAP_USER = "alice"; npm start   # PowerShell
```

管理員登入後右上角才會出現「管理關卡」，可產生並發布有唯一解的關卡。

### 用產題器建立單人關卡

1. 在首頁右上角按「管理關卡」。
2. 輸入關卡名稱，並選擇尺寸。建議從 **7 × 7** 開始；10 × 10
   適合較長的挑戰。
3. 按「產生並發布唯一解關卡」。網站會先產生有連通色塊的地圖，再逐一驗證：
   每色、每行、每列各一隻貓，所有貓彼此不在八方向相鄰格，且全題只有一組解。
4. 成功訊息出現後，關卡立即會出現在單人關卡列表中，並會保存在
   `data/levels.json`，即使重啟伺服器也不會消失。

若產題時間較長，請稍候；發佈前不需要自行檢查答案或色塊連通性。

關卡、訪客進度與帳號資料庫都保存於 `data/`。多人房間僅保留在伺服器記憶體中，伺服器
重新啟動後會自然結束。

玩家斷線後會在短暫寬限期內保留席位，逾時便轉為離線觀戰；房主會自動交接，
對局仍會正常結束。玩家回來時會看到誠實的最新狀態；房間只剩觀戰者後，十
分鐘會自動關閉。
